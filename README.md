<h1>SleekPad</h1>

<p>SleekPad is a smpel and sleek stream deck type a micropad contaning 9 buttons in total, 8 switches and 1 rotary switch, it also contains a horizontal knob compared to the usual vertical one, the design also contains programabel RGB and a programabel Display </p>

<h2>Features:</h2>
<ul>
  <li>Sleak case design on a 25 degre angel</li>
  <li>128x32 OLED Display</li>
  <li>8 SK6812 MINI-E LEDs</li>
  <li>8 Switches</li>
  <li>1 EC11E Rotary encoders (with switch!)</li>
</ul>

<h2>CAD Model:</h2>
<p>The design is made up of 3 layer, the top, middel and bottom, they all join together with the PCB wiht 4 M3 Bolts screwing in to heatset inserts,the board is on a25 degre angel to mimic the stream deck designs </p>
